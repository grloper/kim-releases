Install on Android

  1. Download the APK Tap Download for Android (GitHub Releases — latest APK; file Mothlight-0.6.0-android.apk; listing stills in store/).
  2. Allow install When prompted, allow your browser or Files app to install unknown apps.
  3. Open Mothlight Complete onboarding — first Dream Shelf scene in under five minutes.

The daily loop

  1. Observe & Recall Study a tray. It hides. You name what was there.
  2. Smart Cards Leitner boxes — hard cards return sooner.
  3. Blurt & Check Free recall, then see every gap.

Photographic memory is largely a myth. Scientific American. Kim never promises IQ boosts or dementia prevention.
